# Человечный текст интерфейса

Интерфейс читают на бегу. Каждая надпись должна помогать сделать следующее действие;
если без неё понятно — её нет. Основано на принципах humanizer (признаки «машинного»
текста, Wikipedia: Signs of AI writing) и практике UX-редактуры.

## Убирать

1. **Подзаголовок, повторяющий заголовок.** «Корзина» + «Здесь лежат удалённые файлы» →
   только «Корзина». «Недавние файлы» + «Последние загрузки на диск» → только заголовок.
2. **Пояснение очевидного.** «Нажмите кнопку, чтобы загрузить» у кнопки «Загрузить»;
   «Выберите файл в списке, чтобы увидеть его содержимое» → «Выберите файл».
3. **Рекламу и приветствия.** «Добро пожаловать», «Войдите, чтобы управлять файлами»,
   «Сводка по вашему диску».
4. **Тройки и перечисления ради ритма.** «Профиль, внешний вид, хранилище и параметры» —
   пусть это видно по разделам.
5. **Тире-связки и длинные хвосты.** Одно предложение — одна мысль. Подробности — в подсказке
   (`title`) или в документации, а не на экране.
6. **Описание интерфейса вместо дела.** «В этом разделе вы можете…», «Ниже показаны…».
7. **Повтор в уведомлениях.** «Файл успешно удалён!» → «Файл удалён». Без «успешно» и «!».

## Оставлять

- Последствия необратимых действий («будет стёрт без возможности восстановления»).
- То, что пользователь не может узнать иначе: сроки, лимиты, куда попадёт файл.
- Ошибки: что случилось и что сделать, без кодов для обычных пользователей.

## Форма

- Кнопки — глагол: «Загрузить», «Восстановить», «Удалить навсегда».
- Пустые состояния — одна строка и действие: «Папка пуста» + кнопка «Загрузить файлы».
- Числа с единицами и склонением (`pluralize`), даты — коротко («сегодня, 12:40»).
- Без «Вы» с большой буквы, без восклицательных знаков, без «пожалуйста».
